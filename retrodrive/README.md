# RetroDrive Release Site

Public release pages for RetroDrive:

- `/` — marketing and link hub
- `/privacy/` — privacy policy
- `/support/` — support and contact
- `/terms/` — terms of use
- `/app-ads.txt` — AdMob authorized seller declaration

The site is static and can be published directly with GitHub Pages. For AdMob
verification, publish it as an account-level GitHub Pages site or on a custom
domain so that `app-ads.txt` is available at the hostname root.

GitHub Issues are used as the support contact channel. Keep Issues enabled on
the public repository.
