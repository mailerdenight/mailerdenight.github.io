# 共通サポートUI

ジム歩走ログをベースにした共通UI。初回適用先は /gym-walk-log/support/ です。

## 共通構成

1. 正式アイコン、アプリ名、紹介・プライバシーへの導線、言語プルダウン
2. サポート見出し、説明、App Storeへのリンク
3. アプリ固有のFAQ
4. 最下部の「お問い合わせ」。メール窓口と必要な情報はこの同じカード内に置く
5. 著作権フッター

メールリンクは利用者のメールアプリに件名と必要情報の空欄を用意します。サイトから自動送信は行いません。
連絡先アドレスは本文に表示せず、「メールで問い合わせる」ボタンだけを置きます。

## 他アプリへの適用

HTMLの support-page-config に slug, appId, email, icon, defaultLocale, locales を設定します。
locales の各言語には共通ラベル、アプリ名、faqs を入れます。
各FAQは question と answer の文字列です。
HTMLには既定言語の本文と選択肢をあらかじめ配置し、JavaScriptが無効でも本文を読めるようにします。
support.css と support.js を共有し、アプリ固有の課金・データ保存・機能説明をコピーしないでください。
利用可能な翻訳がない言語を選択肢に追加しないでください。

言語の優先順: URLの lang → 保存された選択 → ブラウザの言語 → defaultLocale。
言語はURLに反映し、アプリ紹介・プライバシーへのリンクにも引き継ぎます。

ジム歩走ログでは既存FAQの内容と10言語を引き継ぎました。
紹介・プライバシーページの既存CSS・翻訳ファイルは変更しません。

作成日: 2026-10-09 (JST)

## プライバシーページ

同じCSS・ヘッダー・言語切替を使い、設定の pageType を privacy にします。
各言語の privacyTitle, privacyIntro, 本文ラベル, updated を設定します。
ポリシー本文の意味と改定日はUI変更で変更しません。お問い合わせはサポートページへのボタンで案内し、メールアドレスを本文に表示しません。


## 全公開アプリへの適用（2026-10-09）

総合案内に掲載する18アプリの正規サポート・プライバシーURLで共通UIを使用します。未公開アプリと旧URLの転送は維持します。本文は各アプリの既存資料を移行し、用意されている言語のみを選択肢にします。English summary は要約と明示します。問い合わせ導線のみ、公開Issuesからメール作成ボタンへ変更しました。data-page-locale の本文はSSRで日本語を表示し、共通JSで選択した言語へ切り替えます。
