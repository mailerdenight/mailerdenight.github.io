サポート

共有できない場合

親子双方のiPhoneでiCloudへのサインインと通信状態を確認してください。共有を受けた側は、招待された子どもの記録を閲覧できます。

通知が届かない場合

iPhoneの設定で本アプリの通知を許可し、記録の返済予定日や曜日を確認してください。通知は予定のお知らせで、返済の記録は行いません。

お問い合わせ

不具合、共有やデータ削除に関する相談は、下のサポートフォームからお送りください。GitHubへのサインインが必要です。公開される投稿に実際の名前や金額などの個人情報を記載しないでください。

サポートフォームを開く

For support, bug reports, or data deletion guidance, use the contact form above. A GitHub sign-in is required. Do not include private names or amounts in a public issue.
