婚活アポログ プライバシーポリシー

制定日: 2026年5月17日

婚活アポログ（以下「本アプリ」）は、ユーザーのプライバシーを尊重し、個人情報の保護に努めます。

1. 取得する情報

本アプリは、ユーザーがアプリ内で入力した情報を端末内に保存します。入力される可能性のある情報には、相手の名前、年齢、職業、メモ、予定、デート記録、写真、その他ユーザーが入力した内容が含まれます。

2. 情報の保存場所

本アプリのデータは、原則としてユーザーの端末内に保存されます。本アプリは、入力されたデータを開発者のサーバーへ送信しません。

3. 第三者提供・広告 SDK

本アプリは、ユーザーが入力した情報を第三者に提供しません。ただし、任意で視聴できるリワード広告を表示するため、Google Mobile Ads SDKを利用します。同 SDK は広告の配信、計測、不正防止のために、IP アドレス、端末識別子、クラッシュログ、パフォーマンスデータ、広告データ、広告との操作情報を取り扱う場合があります。これらにはアプリに入力したプロフィール・メモ・写真・予定は含まれません。詳細はGoogle のプライバシーポリシーをご確認ください。

4. アカウント登録

本アプリは、アカウント登録なしで利用できます。

5. アプリ内課金

本アプリには、機能制限を解除するためのアプリ内課金があります。決済処理はAppleのApp Storeを通じて行われます。

6. 通知・カレンダー連携

本アプリは、ユーザーの許可がある場合に限り、通知機能やカレンダー連携機能を使用します。

7. 広告

本アプリでは、登録枠を追加する目的で、ユーザーが選択した場合にのみリワード広告を表示します。広告を視聴しなくても、買い切りの有料版を購入することで全機能を利用できます。

8. 改定

本ポリシーは、必要に応じて変更されることがあります。
